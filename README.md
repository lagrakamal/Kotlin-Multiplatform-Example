# Kotlin Multiplatform Example

Dieses Projekt wurde im Rahmen einer Hausarbeit erstellt und demonstriert die Verwendung von **Kotlin Multiplatform** zur gemeinsamen Nutzung von Code über mehrere Plattformen hinweg.

## Ziel

- Grundlagen von Kotlin Multiplatform verstehen
- Gemeinsamen Code in einer `shared`-Library nutzen
- Beispielhafte Implementierung für verschiedene Targets (z. B. Android und JVM)

## Hinweis

Das Projekt dient ausschließlich zu Lernzwecken im Rahmen des Studiums.
